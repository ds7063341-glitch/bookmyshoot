BookMyShoot Setup Instructions

Prerequisites

  • Python 3.8+
  • MySQL Server 5.7+
  • pip (Python package manager)
  • Virtual Environment (recommended)

Installation Steps

pip install -r requirements.txt

Edit database/db.py to set your MySQL credentials:

self.host = 'localhost'
self.user = 'root'
self.password = 'your_password'
self.database = 'bookmyshoot'

Execute the SQL schema:

mysql -u root -p < database.sql

Or use Flask CLI:

flask init-db

flask create-admin

Follow the prompts to create an admin account.

python app.py

The application will be available at http://localhost:5000

Environment Variables

Create a .env file in the root directory:

FLASK_ENV=development
SECRET_KEY=your-secret-key-here
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=bookmyshoot

Features

  • User Authentication: Register, login, and manage profiles
  • Photography Categories: Browse different photography services
  • Photographer Listing: View available photographers with ratings
  • Booking System: Create, view, and manage bookings
  • Payment Processing: Multiple payment methods (Card, Razorpay, Bank Transfer)
  • Admin Dashboard: Manage users, bookings, and payments
  • Responsive Design: Mobile-friendly interface

Default Login Credentials

After creating an admin user, you can login with the credentials you provided during setup.

Security Note: Make sure to change the SECRET_KEY in production and enable HTTPS!
